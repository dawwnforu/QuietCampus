# 静档 / Quiet Campus：浏览器本地版使用说明

[English](web-user-guide.en.md)

这是原 Flutter 项目的浏览器本地版。它把档案加密保存在**当前浏览器和当前站点来源**，不要求注册，不含跨设备云同步。Android / Windows 原生客户端的账号、数据库和同步机制保留，但不是本说明中的网页版。

## 入口与设备

当前开发入口是 `http://127.0.0.1:7360/`，只在运行本地服务的电脑上有效，不能发给朋友当公开地址，也不能直接在另一台手机打开。正式手机入口需要另行批准的稳定 HTTPS 部署；本轮没有公开部署。

同一来源的 `?demo=1` 是合成示例体验，**刷新会重置**，不要填写私人内容。真正的本地档案入口没有这个参数。顶部会分别显示“合成示例”或“浏览器本地版”。

Chrome / Edge 桌面浏览器已用于开发验证。手机浏览器的完整实机验收仍待完成；能缩小桌面窗口不等于手机已通过。

## 第一次开始

1. 在本地档案入口设置独立加密口令，至少 12 个字符，再输入一次确认。不要复用邮箱密码。
2. 下载恢复密钥文件，自己核对文件确实存在，再存到安全的离线位置。密钥和完整加密备份不是同一个文件，两者都需要妥善保存。
3. 点击中央“＋”，选择日记、经历或项目，写下内容并保存。返回列表后打开原文核对；刷新后需要重新解锁。

口令错误时可以继续修改，不必清空资料。所有解锁途径都丢失后，开发者无法恢复内容。不要把口令、恢复密钥或私人备份发送给客服。

## 写作与找回

- 在编辑器直接写作，输入 `# `、`- ` 等快捷符号可自动排版；排版帮助列出支持的符号。原始内容以富文本 Delta 保存，不会转换成纯文本。
- 展开“标签与关联”，用 `#` 创建标签，或选择历史标签。标签管理在随笔中，重命名会更新关联；移除标签保留正文和附件。
- 搜索覆盖标题、正文、标签和记录类型。采用规范化后的顺序字符匹配，支持分散字符和重复命中；不是语义理解或错别字纠正。类型按当前语言显示，英文界面也保留原中文类型别名查找。
- 每批列表显示 20 篇，可继续加载；搜索和“导出全部随笔”覆盖全部已加载到客户端的记录。它不是服务端分页。
- 列表中的小兔使用本机规则提供试讲文案，不是本地大模型理解。点开记录查看原文。试讲、动作和高亮不会写回原始 Delta，也不会混入随笔导出。
- 顶部 English / 中文切换界面语言。你写的标题、正文和标签不做翻译。切换语言不应丢失草稿；跨页面、关闭标签页或刷新前仍应先保存。

材料库保留原文件，并可在多条随笔中引用。原声保留声音，不做在线转写；录音须由本人允许麦克风权限。活动日历按设备本地日期显示；系统日历导出由你确认，默认不导出私人正文。浏览器版不承诺关闭页面后的系统通知。

## 备份和恢复

1. 档案 → 设置 → **导出完整加密备份**。核对下载文件，另存到安全位置；浏览器下载提示不等于文件已妥善保管。当前完整快照限 64 MiB，单附件限 20 MiB，单记录密文封装限 2 MiB。
2. 在另一浏览器配置或隔离来源打开本地版，选“从完整加密备份恢复”，输入这份备份自己的口令或恢复密钥，先验证并查看对象、附件、冲突数量。
3. 确认后整体恢复，不做隐式合并。若目标已有资料，必须先导出目标完整备份，核对文件已安全保存并勾选确认，再决定替换；下载请求本身不会放行。恢复后重新打开一篇记录，并检查附件。重复恢复同一快照不重复添加记录。

“导出全部随笔”是**明文 JSON**，“导出明文文本”是单篇文本：都不含完整材料原件，不代替完整加密备份。搜索高亮不导出。

损坏、超限或不支持的备份应拒绝导入，原资料保留。读取失败时不要清理站点数据或卸载浏览器；先保留现状和可读取的备份，在隔离环境验证恢复。网页版本不会自动重建清空数据库。

## 本地保存的边界

更换域名、端口、浏览器配置或设备不会自动带走资料。隐私模式、浏览器清理和存储回收也可能导致数据丢失。请定期备份，并在变更入口前验证恢复；当前不提供自动备份或绝不丢失保证。

多个同源标签页同时编辑时，旧页面的写入会被拒绝。先复制未保存文字并导出当前可读备份，再重新打开最新档案；不要通过清空站点数据“修复”。

当前浏览器版没有在线 AI、广告统计或账号后端。加密钥匙保留在解锁会话内存，锁定后再次输入。浏览器自身、受控设备和恶意客户端更新仍属于安全边界；不要把“本地加密”理解为所有环境都安全。
