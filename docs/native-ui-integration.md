## 数据规模检查与取舍

本工作区未找到 SQLite 账号库，`config.local.json` 不存在，无法量测真实账号体量；没有读取或清理用户真实数据库。原生 SQLite 为记录 ID 建主键，保存密文与待同步状态。解锁/同步后的 `_refresh` 仍读取全部非删除记录并在内存解密；云端已有每次 500 个密文对象的读取批次，最终仍全量对账。没有新增明文全文索引。

1,000 篇、每篇约 260 个字符的合成档案，debug 测试中的全量搜索约 175–264 ms（不同运行会变化，不代表手机性能）。本轮只分批渲染/构建可见列表，没有据此新增数据库索引、明文上传或持久化搜索缓存。后续应以真实体量检查解密、规范化、内存占用与全量对账成本，再决定客户端内存索引/后台计算等方案；端到端加密下服务端不能直接按明文正文搜索。
