## 中文邀请草稿

我在做「静档」，一个安静的个人记录网页，想请你免费试用几天，看看它能否帮你留下想法、经历和小项目，再把它们找回来。小兔采用本机规则回应，不调用在线AI。

内容保存在你当前浏览器中，目前不含跨设备云同步；清理站点数据或换浏览器可能丢失，所以需要定期导出完整加密备份。试用只观察你能否顺利保存、再次找到和恢复记录，不要求你分享日记原文或录屏，也不会收取费用。你可以随时退出。你愿意参加吗？

## English invitation draft

I'm building Quiet Campus, a calm place for everyday notes and small milestones. Would you like to try it free for a few days and see whether it earns a place in your routine?

Notes stay in your current browser; this edition has no cross-device cloud sync. Clearing site data or changing browsers can make notes unavailable, so exporting an encrypted backup is part of the trial. The rabbit's responses use local text rules, not an online AI service.

I'd like to learn whether you can save a note, find it later, and restore a backup. I won't ask for your private writing, passphrase, recovery key, or a screen recording. There is no charge, and you can stop at any time. Would you be interested?

上述文案需在完整能力通过后、本人批准邀请时使用。当前没有公开链接，不附虚假购买入口或收款二维码。

## 参与者任务单（中文 / English）

| 时点 | 自己完成的任务 | 观察的证据 |
|---|---|---|
| 第一次，约10–15分钟 | 创建本地档案并自行保存恢复文件；写一条不含敏感信息的真实记录，加一个标签。/ Create a local archive, keep the recovery file yourself, write a non-sensitive note, and add a tag. | 首条保存是否成功；遇到什么阻碍；帮助分钟。不记录内容。 |
| 同一次 | 刷新/重新打开，解锁后用正文关键词找到记录，再修改一处。/ Reopen, unlock, find the note by a word in its body, and edit it. | 是否找回；修改后内容是否保留；是否需要人工帮助。 |
| 同一次 | 下载完整加密备份，在隔离空环境恢复核对。原环境不清理、不覆盖。/ Export an encrypted backup and verify it in a separate empty environment. Keep the original untouched. | 用户自行确认记录/附件是否一致；不要求上传备份或密钥。 |
| 2–3天后 | 没有人催促时是否再次记录或回看。/ Did you return to write or revisit a note without being prompted? | 自报复用次数与日期；区分主动使用和受邀执行任务。 |
| 结束，约5分钟 | 什么内容值得保留？哪里让你不敢信任？没有小兔你还会使用吗？/ What felt worth keeping? What reduced your trust? Would you still use it without the rabbit? | 记录自愿反馈，不把支持作者当购买需求。 |

人数少只能形成方向性观察，不外推市场规模。保存一次不等于长期采用；点赞、停留时长和演示点击不替代真实记录与找回。

## 记录与问题优先级

观察表见 `web-pilot-observations.csv`，目前只有表头。用自选匿名编号，不填真实邮箱、日记正文或恢复信息。支持时间按实际分钟另记；没有观测填“未观测”，不能填0。删除反馈或退出试用时只处理约定的观察信息，不代替用户删除浏览器档案。

修复顺序：数据丢失/暴露 → 无法开始或交付 → 经常需要人工帮助 → 高频功能缺口 → 视觉细节。发生数据问题先保留原资料与已有备份，停止风险操作；不能让用户先清站点数据来“修复”。只重测受影响路径和关键回归。
