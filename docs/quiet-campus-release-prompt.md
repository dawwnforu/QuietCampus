## 按依赖顺序完成机器可做的工作

### S01：确定版本与真实数据链路

核对现有 APK/Windows 产物的入口、版本、包名、签名及编入的环境，不输出密钥。让交付清单和文件名清楚区分历史 Preview、数据测试版和正式候选，沿用已有机制，不为区别版本随意改变正式包名。

检查账号显示、切换、口令错误保留、显示隐藏及同步状态。只有收到服务器确认才标相应同步成功，不能以队列为空或页面无报错推断另一设备已收到。必要时补上脱敏诊断状态，不记录邮箱以外的私人正文、文件名或任何密钥；诊断导出由用户主动确认。

有可用设备和授权会话时，用唯一虚构标记验证 Windows 保存并重启、Android 收到、Android 修改后 Windows 收到。没有设备/解锁权限就完成复现脚本、必要修复和待验说明，不替用户解锁档案，不以浏览器截图冒充手机实测。

### S02：补齐与发行直接相关的数据可靠性

沿现有实现检查离线写入及重启、失败重试、丢失响应幂等、并发编辑、删除墓碑、附件先于引用就绪、账号隔离、切换账号后本地资料保留。先复用已有测试；发现真实缺口才修复，并补对应最小回归。

在隔离测试目录验证完整加密备份、错误口令、损坏/缺附件/未来版本拒绝、恢复密钥和恢复中断。错误不得触发清缓存后重拉、自动重建档案或静默丢弃原始密文。数据格式变更必须有旧客户端处理、失败回退和合成数据演练；不擅自改变加密算法。

### S03：先完善发行工程，再生成候选包

检查依赖许可、权限、版本递增、环境分离和构建脚本。正式构建缺配置/签名应明确失败，不能回退演示或 debug 签名。客户端只能包含公开配置，不打包管理员密钥、私钥、数据库、用户备份或个人内容。

先提出 Android 测试签名到正式签名的安全过渡方案：签名不一致时不能要求卸载或清数据，必须先验证保留旧包、备份与换装后的恢复路径；未经演练不让用户执行。签名私钥与口令只在安全本地保存，不进仓库、日志或聊天。未获明确授权不创建正式身份密钥或代选托管保管人。

核对 Mac 环境可达性；可达则按实际工具链构建并在许可范围内测试，不可达则准备不含私人数据和凭据的源码交接及明确命令。不要为了上架新建空壳 iOS App。Windows 保留完整运行目录，并验证缺网络仍可读取已解锁的本机档案。

### S04：完成必要产品体验与无障碍

检查中文输入、窄屏、系统大字体、对比度、焦点顺序、按钮语义、错误提示、减少动态效果、麦克风/通知拒绝后自由记录。沿用已有中英文机制，不翻译用户内容。清晰展示当前账号、版本、同步状态和恢复入口，设置只保留必要项目。

保留小兔与原文分离，搜索高亮不写回 Delta 或导出。首发不以端侧 AI 为前置条件；若做模型预研，只用虚构内容在本机验证许可证、下载体积、内存/耗时和耗电，未验收不得接入默认流程或加入云端回退。语音识别 API 已取消，继续原声附件和用户自选的系统键盘听写。

### S05：主体与商店准入资料

读取同目录 publisher-release-basis-20261101.md，执行时重新核对官方规则。逐渠道列 Apple、应用宝、小米、OPPO：主体支持、实际应用类别、APP 备案、版权证明是否必要及可接受替代材料、签名/包要求、费用、证据日期、待确认项。找到官方依据再下结论；登录后才可查的规则标为待本人验证，不把广告开户规则当应用商店准入。

### S06：中国大陆正式环境准备

检查实际加密模型和网络依赖后，准备境内部署的最小 Supabase 兼容架构、容量测算、邮件方案、TLS、访问控制、备份/恢复、升级/回滚与维护手册。以单人能维护为准，不擅自增加微服务或付费组件。

只在本地或明确授权的隔离测试环境演练；不迁移真实测试账号/档案，不替换现有生产/测试服务。核对网站备案与 APP 备案各自适用，不把有域名或有营业执照当作已经满足发行条件。境外 Free 联调结果不能包装成境内部署完成。

### S07：准备与简历胶囊的连接契约

首发不依赖另一产品上线。先用合成数据定义最小、版本化的求职素材交换契约：源应用/记录标识、源版本、实际事件日期与写入日期的区别、本人确认的经历事实、材料引用、授权范围及更新状态。

私人日记和证件默认不共享；原始 Delta 不改写。既有“导出全部随笔 JSON”不包含材料元数据与原件，不能宣称已经完成跨产品完整导入。不可直接共享主密钥、管理员密钥、解密数据库或按邮箱自动合并账号。读取简历胶囊真实代码、确认接收端加密与授权后再实现连接；先不建立空的万能网关。

### S08：形成完整待提交材料与可维护版本

用阶段安排替代承诺发布日期：第一阶段 S01–S02 数据；第二阶段 S03–S04 候选包；第三阶段 S05–S06 主体/发行/环境；第四阶段 S07–S08 联动契约与提交准备。可并行独立材料工作，不能越过真实数据验收发布。外部审核时间单独列，不算机器已完成。
