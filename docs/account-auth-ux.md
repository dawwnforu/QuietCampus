# 0.2.1：看清账号与修改口令输入

最新已交付测试版为 [Android 0.2.3](android-data023-delivery.md) / [Windows 0.2.3](windows-data023-delivery.md)，包含本页账号修复及空档案恢复。后续[原生中英文改动](native-language-accessibility.md)已进入 [0.2.4 测试包](native-data024-delivery.md)，最新交付以该页为准。下方 0.2.1 下载记录为历史，不作为当前首选入口。

继续原 Flutter 客户端。邮箱验证码用于登录账号，独立加密口令用于解密该账号的档案；这不是给邮箱设置密码。

## 本次修改

- 档案页、设置页、创建 / 解锁页及连接失败页显示当前完整登录邮箱，可选择复制；个人资料里的“联系邮箱”是自行填写的信息，不用它判断登录身份。
- 这些入口提供“切换账号”。确认后锁定内存中的档案、停止原账号同步和提醒、退出本机登录，返回邮箱登录页；各账号按原 UUID 分库存放，本机密文、待同步队列、冲突和安全存储中的本机密钥保留。重新登录原邮箱并解锁后才继续同步该账号资料。不自动合并不同邮箱的内容。
- 保留原设置中的“退出账号并清除本机缓存”为另一项明确功能。核对两端账号请选择“切换账号”，无需清数据或卸载。
- 设置新口令、解锁、恢复密钥输入和重设口令均支持显示 / 隐藏，默认隐藏，有明确按钮标签。切换为恢复密钥输入后重新隐藏。
- 新加密口令沿用原加密层要求：至少 12 个 Unicode 字符，两次输入完全一致；不裁剪空格、不自动改大小写、不增加强制字母数字混合条件。建议用较长且独有的口令。
- 长度不足、两次不一致，直接在输入框下提示，保留输入且不发起创建 / 更新。解锁失败或联网创建 / 更新失败也保留当前页面输入供修改；成功或离开页面后释放。不会把口令持久保存到草稿、日志或云端。
- 重设口令仅在服务端确认更新成功后关闭对话框并展示新恢复密钥；失败留在原对话框。原加密算法、格式、原始记录和数据库结构不变。
