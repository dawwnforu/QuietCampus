此演练不接收真实付款、不发送邮件、不上传文件、不产生真实订单或收入。模拟报价为1分，只用于验证交付判断，**不是已批准的0.01元售价**。没有支付解锁功能加入随笔，也没有新增交易后端。

运行：

```powershell
node tool/rehearse-web-delivery.mjs build/delivery/QuietCampus-Web-Candidate-20261026-142541.zip build/qa/delivery-rehearsal-20261026-1
```

脚本拒绝覆盖已存在的演练目录；再次演练请使用新目录名。结果 `REHEARSAL.json`、虚构订单 `SIM-QA-PAID/`、模拟凭据和交付副本都位于 `build/qa/`，不进入公开网站或正式订单统计。

## 已实际检查

| 输入或情况 | 本地实际结果 |
|---|---|
| 仅有返回成功页的订单号 | 模拟服务商查不到匹配付款结果，拒绝交付 |
| 独立的模拟查询返回匹配商品、币种、1分及paid状态 | 只生成一次候选ZIP副本、使用说明和模拟凭据 |
| 同订单再次调用 | 读取已有凭据，标记重复，不再拷贝文件 |
| 脚本重新加载后重复调用 | 仍使用磁盘凭据去重，不依赖进程内集合 |
| 待付款、退款、金额/币种/商品不符、真实订单标记 | 拒绝，不创建交付目录 |
| 已有包但没有完整凭据 | 停止并保留待检查文件，不把中断复制当成功 |
