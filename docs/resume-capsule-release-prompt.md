## 产品定位与边界

简历胶囊是本人掌握的求职经历档案袋：整理经历、证据、简历版本和岗位信息，帮助用户判断与岗位的匹配点，并将确认后的事实用于简历。静档负责大学期间的日常记录与积累，两者相互补充。

经营方向：中国大陆、拟以同一个个体工商户运营；署名/母品牌 DAwwN。全部启动预算沿用人民币 5,000 元上限，共享费用只计一次。先准备可公开使用的免费版本，不增加内购、付费 AI、招聘撮合、自动投递或公开社区。当前已知其为网页产品，不能假装已有 APK/iOS 客户端，也不为凑齐产品家族临时套壳。

用户希望 AI 自行完成本项目必要的可逆本地开发、测试与发行材料；每完成一个子任务汇报后继续独立工作。原有文件和数据不得重置。实名、签署、付款、正式数据变更与公开发布由本人完成或另行明确授权。不能把本地开发授权解释为无限期后台运行。

家族色：青绿 #2F8B7C、珊瑚红 #E87967、雾蓝 #5B7FB5、暖黄 #E9B44C，深绿 #25443E 用于文字/轮廓，暖白 #F7F6F2 用于背景。共用几何圆角、线条重量和留白，不复制 Google 的标志造型或配色分割方式。界面不必每处都用四色，不靠颜色单独传达状态。

静档主符号是档案/书页、青绿为主；简历胶囊主符号是胶囊/履历、雾蓝和珊瑚红为主，以白色镂空蝴蝶作共同标记。小兔/跃兔仍属于静档的陪伴角色，不是开发者个人 logo；不要给所有产品强塞小兔角色。

## C04：与静档建立有授权的单向素材关联

### 契约格式

静档旧草案是 `format: "quiet-campus-career-materials", version: 1`。履历胶囊合成契约是 `format: "dawwn-quiet-materials", version: 1`。两份草案结构不同，分别见静档的 `docs/career-material-contract.md` 和本项目的 `lib/integrations/quiet-materials-contract.ts`。可供合成测试的现有样例位于本项目 `docs/release-readiness/contracts/quiet-materials-v1.example.json`。

以接收端 schema 为对照，核对静档实际模型后确定统一格式。接收端格式使用单个 `record`，其 `sourceRevision` 与 `sourceMutationId` 来自同一源快照。第一批仅选经历和项目，实际事件日期未知则保留 `null`，原件清单默认为空。格式验证通过后，仍需经过认证配对、授权范围校验、客户端加密和来源隔离，才能传输私人素材。

先协商版本化数据契约，用虚构资料验证接收、预览、选择字段、去重、来源追溯、版本变化和撤回关联。沿用源记录稳定 ID 与明确版本；实际事件日期和创建时间分别表示；材料原件与文字摘要分开选择。不能用标题或邮箱当跨产品唯一标识。

初期流向为静档 → 简历胶囊，不回写私人日记，不同步整个保险库。默认只接受用户明确选定的项目、经历、获奖及证明；日记、情绪、证件和原声不自动进入求职库，也不默认转写或 OCR。每次扩大范围重新确认。

同邮箱不等于已经关联身份；需要在两边已认证的本人操作中建立映射，授权范围与档案主密钥分开。一次授权后，在设备已解锁且可运行时更新所选素材；网页关闭/档案锁定时不承诺持续后台推送，不新增常驻跟踪服务。

接收端必须先具备与隐私承诺一致的客户端保护；否则只完成契约和合成样例，不接入真实档案。不能向两端服务器、模型或日志发送源主密钥、明文日记或未选择的资料，不把直接共用数据库/管理员权限当集成捷径。

重复传入同源同版本不新增副本；源更新先列差异，保留用户编辑过的简历内容；源删除或撤回停止后续读取，提示已形成的本地副本和已导出文件如何处理，不能保证收回已导出的文件。过期请求、越权、断网、中断、未知版本都保留既有资料并给出明确状态。

## C05：私人数据与匹配计算

对于从静档关联的资料，日记明文、提示词、生成结果和向量/嵌入不得自动上传在线 AI、遥测或日志。不得设置失败后自动云端推理回退。必须把所有现有在线 API 调用点列清楚，不能只隐藏前端按钮而保留后台调用。

如果既有简历胶囊使用在线 AI，先保持资料关联默认关闭，完成独立来源的数据处理说明和开关边界；不得在未确认前导入静档资料进行云端测试。涉及本人已有数据时先给兼容和恢复方案，不静默重写数据库或更换加密机制。

生成结果、匹配索引与源文档分开，持久化私有缓存也要按确定的客户端加密方案保护；导出前预览内容。先核实真实攻击面与所用技术，再做必要实现，不为营销写无法验证的“绝对安全”“开发者永远无法读取”承诺。
