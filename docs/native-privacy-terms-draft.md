## 隐私说明候选正文

静档用于保存和回看本人的随笔、活动、经历、项目及证明材料。账号登录邮箱与档案的独立加密口令用途不同。我们不会接收解密口令、恢复密钥或明文档案主密钥；用户需自行保管可用的解锁方式。全部解锁方式丢失时，客服不能恢复内容。

原生客户端将档案正文、标题、标签、材料信息和原文件名在设备上加密后保存、同步。服务器处理登录邮箱、验证码验证与必要账号信息，以及对象 ID、密文大小、版本和网络请求等元数据；服务提供商和部署地点将在正式版本中列明。网络服务不是完全不可见用户信息。

| 数据/功能 | 设备处理与上传范围 | 用户选择 |
| --- | --- | --- |
| 邮箱登录 | 邮箱、验证请求及登录会话通过认证服务；本机凭据使用系统安全存储 | 用户主动登录；切换账号与删除账号分别提供 |
| 随笔/档案/标签/活动 | 设备解密显示；原生本地 SQLite 保存密文与待同步状态，云端接收密文 | 主动创建、修改、删除、导出 |
| 材料和原声 | 导入/录制后加密保存；启用现有同步时传输加密附件 | 主动选择具体文件或开启录音；不默认 OCR/转写 |
| 搜索、统计、小兔试讲 | 已解锁设备内存中处理；当前不调用在线 AI | 查找原文；小兔文字不是用户原话 |
| 本地通知 | 使用本人设置的提醒时间，默认隐藏具体内容；系统可能受静音/省电影响 | 首次主动开启时请求通知权限，可撤回 |
| 系统日历 | 用户确认后可将所选日程时间及名称交给系统日历，默认隐藏名称；系统副本可能随系统账号同步 | 可不添加或在系统日历中修改/删除，不是应用内双向日历同步 |
| 导出和备份 | 全随笔 JSON/单篇文本是明文且不含原件；完整加密备份另提供 | 预览与确认后选择保存位置，自行保管 |

麦克风只用于本人主动录制，不做后台持续录音或语音识别；录音和播放的设备/系统缓存能力需按平台验证。用户主动使用系统键盘听写时，联网行为由键盘/系统及其政策控制，不由静档提供识别服务。

部分 Office / 文本文件交给外部应用预览时，会先请本人确认，再生成一份本应用私有临时明文副本；该预览目录在静档下次启动时清理，第三方查看器另存的副本仍由用户自行管理。图片/PDF 与原声使用本机字节预览路径。系统文件选择器也可能接入用户自己的云盘来源，不能将这些用户主动选择的外部处理描述成“所有文件永不离开设备”。组件、权限及各平台范围见 [0.2.4 核对清单](native-sdk-data-inventory.md)。

当前没有广告、用户发现、公开主页或第三方在线 AI。未来简历胶囊关联将默认关闭，只共享本人明确选定的求职素材，另行说明范围与停止方式；本轮尚未上线，不因相同开发者或相同邮箱而自动复制档案。

切换账号保留原账号本机密文、队列和冲突。明确的“退出账号并清除本机缓存”是另一项操作；不将其用作故障修复步骤。用户可通过应用导出、修改和发起账号删除；永久删除需要验证本人。删除云端数据不能收回用户已导出文件、其他离线设备副本或未到清理期限的运维备份。备份保留周期、删除处理时限和申诉联系方式须在正式运营前确定并披露。

端到端加密不能防止已被控制的设备、恶意客户端更新或用户主动导出的明文泄露。版本升级不得因此减少账号隔离和恢复保护。现有新加坡 Free 服务仅用于虚构资料联调，不作为中国大陆公开服务的既定部署说明。

## 使用条款候选正文

静档首版拟免费提供个人记录与归档功能，无内购；不承诺无限存储、永久托管、永久免费升级或所有厂商设备通知准时。正式支持系统版本、存储上限和支持范围以实际发行版本说明为准。

用户保留自己内容的权利；为存储、同步及用户主动发起的导出，服务仅处理完成这些功能所必需的数据，不取得公开展示用户日记或训练模型的授权。第三方组件依其许可分发，本项目未向用户授予业务源码的开源许可。

小兔回应、后续可能提供的经历整理建议均需与用户事实区分，不代替专业建议，不保证求职结果。未经本人确认，不自动生成或提交简历，也不与第三方机构分享资料。

重大更新、停止服务或部署变化的通知方式、合理导出窗口及费用变化规则待运营者确认；不能以此草稿承诺具体服务时长。发生保存、同步或恢复故障时保留本机资料，提供安全排查，不要求先删库、卸载或放弃未同步记录。
