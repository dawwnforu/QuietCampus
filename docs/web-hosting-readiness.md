# 浏览器本地版：公开托管前置条件

核对日期：2026-10-26。当前没有购买域名、注册新服务、签约、配置DNS、公开上传或收款。此文是待审阅的部署材料，不是上线证明。原安卓/Windows的Supabase部署不受影响。

## 为什么网页仍需要托管

Windows解压包的7360服务仅监听127.0.0.1，另一台手机不能靠这个地址访问。面向普通手机用户需要稳定HTTPS来源，托管的是Flutter程序、字体和说明；此浏览器版本不需要新增账号数据库、Supabase项目或文件上传接口。笔记和原件仍在用户浏览器的加密IndexedDB中。主机/CDN仍可收到IP、时间和请求路径等访问元数据，不能宣传“没有任何数据经过第三方”。

## 当前仅准备一个技术候选

Cloudflare Pages Direct Upload适合这份纯静态构建：可使用平台提供的`<项目名>.pages.dev`地址，不必先购买域名；账号条款和最终上传由本人确认后再操作。其Free页面上限20,000文件、单文件25MiB；控制台拖放另限1,000文件。[官方限制](https://developers.cloudflare.com/pages/platform/limits/)、[Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)。本轮构建检查使用更严格的1,000文件和25MiB门槛，不把约70MB的Windows整体ZIP当单个网站资源上传。

部署对象**仅为`build/web-product/`内的静态文件**，其中`index.html`位于上传根部。不要上传仓库、Windows runtime、build/qa、数据库、备份或配置密钥。已准备`_headers`，要求no-store、nosniff及no-referrer；这是Pages识别的静态配置，[格式依据](https://developers.cloudflare.com/pages/configuration/headers/)。最终响应头和完整网站运行要等真实部署后测，文件存在不代表平台已执行。

该候选没有中国大陆连通性/速度/手机浏览器验收，不保证长期免费或中国大陆可达；不适合作为已经确认的大陆正式发行路径。当前只把它列为待批准的免费演示/小范围验证技术候选。没有新增付费R2、Workers、统计、Zaraz或第三方AI，也不因大包直接升级付费。

## 域名和HTTPS

首轮不需要自有域名。若后续决定品牌域名，需要本人确认注册人、域名、首年和续费金额，再由本人实名和付款。不能用尚未购买的名称冒充正式入口。自有域名需先在Pages中关联，再按类型配置DNS；根域和子域的接入要求不同，按[官方自定义域名说明](https://developers.cloudflare.com/pages/configuration/custom-domains/)处理。证书生效、HTTP跳转和手机外网访问都须实测，不要求用户忽略证书警告。

**来源是数据边界。** `http://127.0.0.1:7360`、`https://项目.pages.dev`、品牌域名和每个预览域名是不同档案空间。更新应持续使用同一正式来源；不要每版发不同预览域名让用户误以为数据消失。从本机迁到公开站、换域名或回滚前：先导出完整加密备份 → 在隔离环境验证能解锁且原件可读 → 本人确认后在目标来源恢复。保留旧来源资料，不清数据库。

## 大陆运营的待确认条件

官方规则区分经营性互联网信息服务的许可和非经营性服务的备案；具体业务应按运营主体、住所、接入、实际服务及收费方式判断。[现行《互联网信息服务管理办法》](https://sdca.miit.gov.cn/zwgk/fgbz/art/2026/art_fea940f81f1d423e87101adf147ab979.html)、[《非经营性互联网信息服务备案管理办法》](https://www.miit.gov.cn/zcfg/xxtxl/art/2024/art_7c8cc677bfb7433e93e31bbad81142ef.html)。

因此，不能仅因“卖的是ZIP”就断言一定需要某许可，也不能仅因选择境外主机就认定无需履行任何大陆义务。目前缺本人拟运营地区/主体、接入服务商对本业务的审核及付费方式，尚不能宣布备案/许可条件已满足。若转向境内接入，须先向所选接入服务商和相应省通信管理局核对类别、个人主体适用范围、域名实名与所需材料；不先替本人登记公司或购买主机。本轮浏览器网站准备不等于原生APP备案完成。

上线前还需填定运营者、可联系渠道、数据说明、软件使用许可、更新/支持范围及适用售后。现有privacy.html和商品范围均为草案，不应把缺失字段在公开条款中伪装成已确认。

1. 审阅主体/地区、产品署名与支持联系方式，确认仅免费小范围体验；约10–20分钟。成功标志：没有占位身份/联系方式，部署范围明确。
2. 阅读并自行接受所选平台协议、登录；不提供密码或验证码给聊天，不绑定卡、不升级；约10分钟。成功标志：本人可进入免费Pages控制台。
3. 明确授权上传这份已审阅的静态目录；部署后用电脑和手机移动网络执行保存、重开、搜索、编辑、备份及隔离恢复；约20–30分钟。成功标志：实际HTTPS入口及相应记录/原件验证通过。

没有部署授权时停在可审阅文件，不点击Deploy。后续可由助手准备和操作获准的非凭据步骤；付款、协议及实名仍由本人完成。
