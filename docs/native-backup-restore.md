# 原生完整加密备份恢复

更新：2026-11-02。源码版本 0.2.3+5；Android / Windows 新包的构建和设备验收以发行进展为准。此前交付的 0.2.2 APK 不包含本页的新入口。

## 入口与操作

在原生客户端登录**备份原账号**，到达尚未解锁的页面后：

1. 选择“从完整加密备份恢复到空档案”，选完整加密备份 JSON；不是“导出全部随笔”的明文 JSON。
2. 在客户端输入备份的加密口令，或选择恢复密钥；验证成功后查看对象、附件和冲突数量。
3. 确认恢复。档案仍保持锁定，主动解锁后才使用原同步流程与云端对账。不要把口令或恢复密钥发给协作者。

没有要求卸载、清缓存或删除任何数据库。已有资料、附件草稿或冲突的设备不会整体替换；请保留该设备的原档案。正式签名换装仍需另做实机演练，本入口不是让用户现在卸载的依据。

## 已实现的保护

- 沿用 `quiet-campus-backup` v1、原 Quill Delta、XChaCha20-Poly1305 和 Argon2id；无数据库迁移或加密格式更改。
- 在内存认证每条记录、删除标记、富文本、材料引用及附件；错误口令、篡改、缺附件和未来版本拒绝导入。
- 只接受同账号、与当前账号密钥封装一致的备份。验证后和提交前再次检查账号、密钥封装及空档案状态。
- 导入在 SQLite 的单个 `BEGIN IMMEDIATE` 事务中保存原密文、修订号、待同步变更标识、本机 generation、墓碑、冲突和附件；失败整体回滚，当前密钥封装与原库不替换。
- 导入本身不请求网络、不写系统解密密钥、不解锁、不启动同步。解锁后的附件先于待同步记录补传；云端新版本和删除继续进入原有冲突处理，不自动覆盖或复活。
- 验证错误保留输入，口令可显示/隐藏；取消预览不写数据库，关闭对话释放备份解锁密钥。

## 明确限制

- 当前完整备份导入上限为 **64 MiB**，单附件 20 MiB；这是文件大小限制，不是可用账号或服务容量承诺。原生导出可产生更大的备份；超限文件需保留，不能靠删除原档案来导入。
- 已修改口令/恢复密钥而使封装不一致的旧备份目前拒绝导入；旧备份仍可通过独立离线解密工具验证和取回资料。本版不替换当前封装，也不实现旧/新密钥流程或跨账号迁移。
- 不合并到非空本机档案，不修复损坏 SQLite，不提供未验证的自动修复或账号重建。
- 本机组件测试不是实际 Android/iOS 文件选择器、换装、云端同步或服务器恢复验收。
