# Web-only font subsets

Generated from this repository’s unchanged `assets/fonts/NotoSansSC-Regular.otf` and `LXGWWenKaiLite-Regular.ttf`, using `tool/subset-web-fonts.py`. Original copyright/license name records are retained. Modified web font family names are **Quiet Portal Sans** and **Quiet Portal Display**. These are fixed-page WOFF2 subsets, not a replacement for full fonts in the Flutter editor or a standalone font product.

OFL source license files are copied into the delivered `fonts/` directory. Original notices and source/version references remain in `THIRD_PARTY_NOTICES.md`. The subset covers the actual landing-page and guide copy plus printable ASCII; user writing continues to use the full original fonts. If fixed copy changes, regenerate and inspect coverage and layout.

Build tools used: fontTools 4.67.0, brotli 1.2.1, zopfli 0.4.3, installed only in the workspace tooling directory. They are not shipped to users.
